# S0438 Resource Metadata

必需字段（页内 Required metadata fields 列表）：title、description、publishing organization、type、license、contact(s)、creator(s)、metadata provider(s)；推荐 sampling methodology 与 citation。逐条引用时注意该列表是 bullet list，不能合并成一行当引文。

## 摘录（逐字，不得改写）

- **§How to write resource metadata**：

  > Ultimately your metadata needs to be transformed into an XML metadata document. The XML must conform to the GBIF Metadata Profile, which is based on the Ecological Metadata Language (EML).

  说明：支撑：eml.xml 要按 GBIF Metadata Profile（EML 派生）写，不是随便一份 EML

- **§Template**：

  > No Excel template exists for resource metadata. Simply use the IPT's built-in metadata editor to populate the metadata.

  说明：支撑：资源级元数据没有 Excel 模板，只能手写 EML 或走 IPT 编辑器 —— 本站既然要脚本生成，就得自己产 eml.xml
