# S0436 Darwin Core text guide

2026-10-13 版规范（本页面 Date version issued）。默认值：fieldsTerminatedBy=`,`、linesTerminatedBy=`\n`、fieldsEnclosedBy=`"`、encoding=UTF-8、ignoreHeaderLines=0；示例里 tab 写作 `\t`。本轮用于回答「DwC-A + EML 要怎么做」，尚未写进仓库文件（实现 build_dwca.py 时补 used_in）。

## 摘录（逐字，不得改写）

- **§2 Metafile content**：

  > The metafile MUST be named `meta.xml`.

  说明：支撑：DwC-A 的 meta.xml 文件名是硬性要求，不能叫别的

- **§2.1 The `<archive>` element**：

  > The `<archive>` element SHOULD have a `metadata` attribute.

  说明：支撑：meta.xml 里应挂 metadata 属性指向 eml.xml

- **§2.1.1 Attributes（metadata 行）**：

  > The format of the metadata is not prescribed, but a standardized format such as Ecological Metadata Language (EML), Federal Geographic Data Committee (FGDC), or a format from the ISO 19115 family is RECOMMENDED.

  说明：支撑：EML 是 GBIF/TDWG 推荐（非强制）的 archive 级元数据格式

- **§2.2.1 Attributes（rowType 行）**：

  > The row type is REQUIRED and MUST be a Uniform Resource Identifier (URI) for the term identifying the class of data represented by each row.

  说明：支撑：checklist core 的 rowType 写 http://rs.tdwg.org/dwc/terms/Taxon

- **§2.2.2 Elements（`<id>` 行）**：

  > If extensions are being used, the `<core>` MUST contain an `<id>` element, which indicates the identifier for a record.

  说明：支撑：加 VernacularName 扩展时 core 必须声明 `<id index="0"/>`，扩展必须声明 `<coreid index="N"/>`

- **§2.4.1 Attributes（index 行）**：

  > `index` | Specifies the position of the column in the row. The first column has an index of 0, the second column has an index of 1, etc.

  说明：支撑：字段列号从 0 起，写 meta.xml 时列序必须与 CSV 一致
