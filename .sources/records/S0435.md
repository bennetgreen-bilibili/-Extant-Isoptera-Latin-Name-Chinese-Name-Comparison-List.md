# S0435 数据集（Dataset、DataCatalog、DataDownload）结构化数据 | Google 搜索中心

2026-11-13 抓取，页面为 zh-cn 版本；同日 Search Console 中站点 3089 个物种页 / 1071 个分类页报 Dataset 四字段缺失。

## 摘录（逐字，不得改写）

- **§结构化数据类型定义 → Dataset 属性表 → 「hasPart 或 isPartOf」行**：

  > 这两种属性都可采用网址或 Dataset 实例的形式。如果将 Dataset 用作值，则必须包含独立的 Dataset 所需的所有属性。

  说明：支撑：isPartOf 的值若是 Dataset 实例，就必须自带 name / description / license / creator；本站原先在 1071 个分类页与 3089 个物种页写 {"@type": "Dataset", "@id": "...#dataset"} 这种只有 @id 的带类型实例，正是 Search Console 报「未填写字段 name / description / license / creator」的原因。改法：只留 {"@id": ...} 或直接用网址。

- **§结构化数据类型定义 → Dataset 段首**：

  > 如需了解 Dataset 的完整定义，请访问 schema.org/Dataset。

  说明：支撑：字段清单以 schema.org/Dataset 为准（name、description 为必要属性；creator、license、distribution 为建议）。
