# S0431 Managing a custom domain for your GitHub Pages site

## 摘录（逐字，不得改写）

- **§ About custom domain configuration，¶2**：

  > Make sure you add your custom domain to your GitHub Pages site before configuring your custom domain with your DNS provider. Configuring your custom domain with your DNS provider without adding your custom domain to GitHub could result in someone else being able to host a site on one of your subdomains.

  说明：支撑：操作顺序必须是「先在 Settings → Pages 填域名，再去 Cloudflare 建记录」

- **§ Configuring an apex domain，步骤 4**：

  > If you are publishing from a custom GitHub Actions workflow, no `CNAME` file is created, and any existing `CNAME` file is ignored and is not required.

  说明：支撑：本站走自定义 Actions 发布，不需要、也不应添加 CNAME 文件

- **§ DNS records for your custom domain，表格「Apex domain / A」行**：

  > 185.199.108.153
  > 185.199.109.153
  > 185.199.110.153
  > 185.199.111.153

  说明：支撑：apex 的 4 条 A 记录值

- **§ DNS records for your custom domain，表格「Apex domain / AAAA」行**：

  > 2606:50c0:8000::153
  > 2606:50c0:8001::153
  > 2606:50c0:8002::153
  > 2606:50c0:8003::153

  说明：支撑：apex 的 4 条 AAAA 记录值

- **§ Configuring an apex domain and the `www` subdomain variant，¶3**：

  > Ensure that the `CNAME` record points directly to `<user>.github.io` or `<organization>.github.io` without including the repository name.

  说明：支撑：www 的 CNAME 指向 bennetgreen-bilibili.github.io，不带仓库名

- **§ Configuring an apex domain，步骤 4**：

  > Optionally, to enforce HTTPS encryption for your site, select **Enforce HTTPS**. It can take up to 24 hours before this option is available.

  说明：支撑：Enforce HTTPS 可能要等 24 小时才出现
