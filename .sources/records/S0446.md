# S0446 网站换了域名，GSC地址变更怎样提交？

二手教程。另记：文中提到「整个旧域迁到另一域的目录则可以，例如 example.com 搬到 example.net/archive/」，与「旧来源带目录不行」是两条不同规则，别混。

## 摘录（逐字，不得改写）

- **§准备同一账号和每个旧主机的去向**：

  > 工具所说“域名层级”，指旧来源没有目录路径。example.com网域资源和根网址前缀资源都可用；example.com/products/这样的目录资源不能作旧来源。

  说明：支撑：旧来源必须是域名或根前缀；本项目 github.io/<repo>/ 是目录资源，故工具不可用

- **§开篇摘要**：

  > 这个账号在两边都要是“所有者”；旧www和其他子域也要分别处理。

  说明：支撑：权限要求为所有者（Full user 不够）

- **§用同一个产品页观察，并保留旧入口**：

  > 旧跳转不要随180天通知一起停掉。Google完整迁移指南建议跳转一般至少保留一年

  说明：支撑：180 天通知窗口与跳转保留期是两件事
