# S0445 网站迁移与 GSC 地址变更：跳转及验证清单

二手教程（非 Google 官方）。同一页的迁移类型表把「blog.example.com → example.com/blog/」「http→https」「www 去 www」「同域改路径结构」都列为不必用地址更改工具，与本项目适用的判断一致。Google 官方 9370220 与 developers.google.com 在本网络超时不可达，未能核对原文。

## 摘录（逐字，不得改写）

- **§换域名时，用“地址更改”工具**：

  > 在旧网站的资源里，打开“设置”→“地址更改”，选择新资源并提交。Search Console 会先抽查一部分页面的跳转是否正确，通过后才接受。

  说明：支撑：工具入口路径与提交前的跳转预检行为

- **§换域名时，用“地址更改”工具**：

  > 这个工具只能用于域名级别的资源，不能用于目录。

  说明：支撑：带目录路径的属性不能作旧来源——本项目旧站是 github.io 下的项目子目录

- **§换域名时，用“地址更改”工具**：

  > 新旧两个网站都要在 Search Console 里验证，并且用同一个 Google 账号、以所有者身份管理；

  说明：支撑：两站同账号 + 所有者权限是前置条件

- **§跳转要保留多久**：

  > Google 的建议是尽可能长，一般至少一年，让各种信号完成转移，其他网站上指向旧网址的链接也继续有效。

  说明：支撑：旧仓库与其 Custom domain 不能删，301 要长期保留
