# S0433 Securing your GitHub Pages site with HTTPS

## 摘录（逐字，不得改写）

- **§ Verifying the DNS configuration，¶2**：

  > Any additional `A`, `AAAA`, `ALIAS`, `ANAME` records with the `@` host, or `CNAME` records pointing to your `www` subdomain or other custom subdomain that you would like to use with GitHub Pages may prevent the HTTPS certificate from generating.

  说明：支撑：apex 上不能有多余记录（Cloudflare 建站时可能自动生成），否则证书签不出来

- **§ Troubleshooting certificate provisioning ("Certificate not yet created" error)，¶2**：

  > If the process has not completed several minutes after you clicked **Save**, try clicking **Remove** next to your custom domain name. Retype the domain name and click **Save** again. This will cancel and restart the provisioning process.

  说明：支撑：域名已正确解析但证书迟迟不出时的重试操作

- **§ About HTTPS and GitHub Pages，Note**：

  > the entire domain name of your GitHub Pages site must be less than 64 characters long for a certificate to be successfully created.

  说明：支撑：termite-extant-isoptera.org 共 28 字符，满足证书长度要求
