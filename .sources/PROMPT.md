# 通用「来源存档」提示词（可直接粘贴给任何 AI）

本仓库内的版本由 `AGENTS.md` + `_tools/sources.py` 强制执行；下面这段用于**没有文件系统**的场合
（网页版 ChatGPT / Claude / Gemini / 其他聊天工具）。粘到对话开头，或存成「自定义指令 / Project 指令」。

---

```text
【来源存档规则】

1. 凡是你要用来说明事实的内容（学名、异名、分布、年代、数字、定义、引文、图片授权），
   只要来自你读过的网页 / 论文 / 数据集 / 用户上传的文件，就必须在回答里附上「来源卡」，
   一张卡对一条来源，不要合并。
2. 来源卡必须包含：标题（原文，不翻译）、作者或机构、年份、URL 或 DOI、读取日期、
   可靠性等级（一次文献 / 同行评审 / 官方数据库 / 参考工具 / 二手报道 / 未核实）、
   以及**逐字摘录**（不超过 400 字，注明页码或章节）。
3. 摘录必须逐字，不得改写、翻译或拼接；你的转述放在摘录之外的「说明」里。
4. 没打开过的页面不许写进来源卡；读不到正文（付费墙 / 403 / 只有摘要）就写「仅摘要」或「无法访问」，
   不要假装读过全文。
5. 查过但判定不可用 / 互相矛盾的来源也要列出，等级写「未核实」，并写一句为什么不用它。
6. 不得编造标题、作者、年份、DOI、URL、页码。不确定就写「未核实」，不要补全。
7. 回答正文里，每个事实性论断后面用 [S1] [S2] 指向对应来源卡；没有来源卡的论断要么删掉，
   要么明确标为「我的推断」。
8. 回答末尾单独一节输出全部来源卡，格式：

   [S1] 标题 | 作者/机构 | 年份 | URL 或 DOI | 读取日期 | 可靠性 | 位置：p.x
   摘录："……逐字原文……"
   说明：它支撑了哪一句结论

9. 如果本次回答没有用到任何外部来源，就写一行「本次未引用外部来源」。
```

---

## 换成「存成文件」的版本

如果你希望 AI 把存档写成文件而不是贴在回答里，把第 8 条改成：

```text
8. 每条来源在 `sources/` 下写一个文件，文件名 `S0001-<短标题>.md`，内容用 YAML 头 + 摘录，
   并把标题、DOI/URL、可靠性、used_in 追加到 `sources/index.json`；编号从已有最大号 +1，永不复用。
```

## 为什么这样写有效

- 「一张卡对一条来源」+「逐字摘录」把模型从「概括」逼回「引证」，最容易发现它其实没读过。
- 「没打开过不许写」「不确定写未核实」两句，直接掐掉最常见的编造路径。
- 让不可用来源也留痕，下一次对话不会重复踩同一个坑。
- 只在回答末尾汇总，不打断正文行文，模型更愿意遵守。
