# 文献检索器（/papers/）说明

> 目标：让读者按**拉丁学名 / 中文名 / 多个关键词**找白蚁相关论文，并直接看到摘要、复制引用。
> 纯静态实现：不引入后端、数据库或 API Key；查询在浏览器里直接发往 OpenAlex / Crossref。

## 1. 页面与入口

| 页面 | 文件 | permalink |
|---|---|---|
| 中文 | `papers.md` | `/papers/` |
| English | `en/papers.md` | `/en/papers/` |
| Español | `es/papers.md` | `/es/papers/` |

- 导航「文献 / Papers / Artículos」进入；三语共用一套模板与脚本。
- 物种页在「其他数据库」之后增加「相关文献」区块：显示本属 top 3（含完整摘要）+ 「检索本种（含异名）」按钮。
- 静态资源：`assets/papers.js`、`assets/papers.css`；文案在 `_data/i18n.yml` 的 `nav_papers` / `papers_*` key；三语 key 必须一致（`check_site.py` 会检查）。

## 2. 数据源与检索式

| 来源 | 接口 | 用途 | 备注 |
|---|---|---|---|
| OpenAlex | `https://api.openalex.org/works` | 主检索源 | CORS `*`；默认 `title_and_abstract.search` 精确短语，勾选「全文检索」时改用 `default.search`；CC0。无 API key 时按出口 IP 共享每日额度，用尽会 429 |
| Crossref | `https://api.crossref.org/works` | 补充 DOI / 期刊 / 摘要 | CORS `*`；带 `mailto`；相关性排序较弱，需去重 |
| Semantic Scholar | `https://api.semanticscholar.org/graph/v1` | 单条缺摘要时兜底 | 只按 DOI 单查，避免触发 429 |
| 本站缓存 | `papers-index.json` | OpenAlex / Crossref 都失败时兜底 | 属级、含完整摘要 |

> OpenAlex 额度用尽时，`build_papers.py` 会自动对失败的属回退到 Crossref 检索（`source: crossref`，摘要覆盖率更低）；也可以显式加 `--crossref-only`。设置 `OPENALEX_API_KEY` 环境变量可使用自己的 OpenAlex 额度。

检索式（前端 `assets/papers.js`）：

1. 输入命中 `search-index.json` 的种 / 属时，使用规范拉丁名；
2. 拉丁名一律用**精确短语**，如 `"Coptotermes formosanus"`；
3. 勾选「包含次异名」时把 `search-index.json` 的 `s` 字段按 `;` 拆开，生成 `("接受名"|"异名1"|"异名2")`；
4. 未命中分类群时按**多个关键词**处理：空格 / 逗号 / 分号 / 顿号分隔（引号内视为短语），最多 8 个；**关键词之间是 AND**，每个关键词内部与常见中英别名之间是 OR，如 `"分子"|"molecular"`；
5. 关键词默认搜 `title_and_abstract.search`（标题+摘要，精确）；勾选「全文检索」改用 `default.search`（含全文，召回更高、噪音更大）；
6. 默认追加**白蚁范围过滤器**（`termite` / `isoptera` / `白蚁` / `等翅目` + 常见属名，全部 OR），再与关键词 AND；取消「仅白蚁文献」可查全库；
7. 「仅中文文献」追加 `language:zh`，并把检索词换成该分类群的中文名；
8. 固定追加 `type:article|review|book-chapter|preprint`，排除 dataset / paratext 等非论文记录；
9. 排序：相关度（默认）/ 最新（`publication_year:desc`）/ 被引（`cited_by_count:desc`）。

> 常见中英术语互扩只做整词映射（分子↔molecular、系统发育↔phylogeny、肠道↔gut、微生物↔microbiota 等），不做语义猜测；这样中文关键词也能命中英文论文。Crossref 是相关性检索，合并前会用标题+摘要做一次本地校验，避免把无关结果带进来。

## 3. 摘要策略（按用户要求：完整摘要入库）

- OpenAlex：取 `abstract_inverted_index`，按词位置排序还原为文本；去掉开头的 "Abstract" 标签。
- Crossref：取 `abstract`（JATS XML），去标签、解 HTML 实体、折叠空白；只在 OpenAlex 缺摘要时补。
- 缓存：`build_papers.py` 保存**完整摘要**；仅当超过 `MAX_ABSTRACT_CHARS = 20000` 字符时截断并置 `abstract_truncated=true`（本次缓存 0 条截断）。
- 单条结果缺摘要：结果卡显示「暂无摘要」+「尝试获取摘要」按钮；依次查 Crossref DOI、Semantic Scholar DOI，成功后写入 `sessionStorage`。
- 覆盖率：开放元数据里约 **60–70%** 条目带摘要（本次缓存 68.4%；OpenAlex top 50 实测：种级 46%、属级 50%、中文 54%）；页面不会伪造摘要，缺摘要时给 DOI / OpenAlex / 外部平台链接。
- 版权：摘要版权归原作者 / 出版方；页面显示来源并注明「仅用于检索参考，请以原文为准」。不下载 / 不存储 PDF，不抓出版社 HTML 或知网页面。

## 4. 摘要翻译：名录 + 术语表驱动（中英互译，前端，免 API Key）

结果卡摘要下方有「目标语言 + 翻译摘要」控件：中文 / English / Español。全部在浏览器里直连，不需要后端、数据库或密钥。

**干预范围**：只有中文 ↔ 英文互译会使用本站名录与术语表；西班牙语目标仍为纯机器翻译（未做西语术语表）。

| 层 | 数据 | 作用 |
|---|---|---|
| 1 名录 | `search-index.json`：3428 条（支系 6 / 科 13 / 亚科 18 / 属 323 / 种 3004 / 亚种 64）+ 905 个次异名 | 翻译前把学名换成 `[[n]]` 占位符，译完还原成中文正名 / 拉丁名；中文译文首次出现写成「台湾乳白蚁（Coptotermes formosanus）」，后续只写中文名；亚种拼成「种中文名（亚种中文名）」 |
| 2 术语表 | `_data/translation_glossary.yml`（version 3：mask 153 条 / post_zh 32 条 / 名录外名称 14 条） | `mask`：多词/罕见术语遮蔽后还原，分三组——**昆虫形态/解剖 90 条**（head capsule→头壳、pronotum→前胸背板、antenna→触角、mandible→上颚、tarsus→跗节、tergite→背板、gizzard armature→砂囊结构、enteric valve→肠瓣…）、行为/生态/生活史、生理/生化/防治；`post_zh`：中文译文高频错译纠正（工人→工蚁、殖民地→巢群、头舱→头壳、天线→触角、股骨→腿节…），每条带 `when` 英文词守卫，避免误伤其他语境 |
| 3 缓存 | `localStorage` | 按「原文 + 方向 + 术语表版本 + 名录条数」哈希（`papers-tr:v2:`，最多 40 条），术语表改版或名录更新后旧译文自动失效 |

- **提供方链**：MyMemory（CORS `*`，单次 ≤500 字符，按访客 IP 约 5000 字符/天，用尽后改用站点联系邮箱额度）→ Google 非官方接口 → 可选自建 LibreTranslate（`data-translate-url` / `data-translate-key`，配置后优先级最高）。接口返回 HTTP 429/403 或额度警告时按「额度用尽」处理（走邮箱额度重试 → 再降级），界面提示额度而不是通用错误。
- **分块**：按空白边界切块，MyMemory 每块 ≤420 字节（留出占位符余量）；中文等无空格文本按字符硬切。**形态/术语密集时占位符会撑破 500 字符上限，此时自动沿句号/逗号/空格二分重切再保护**（不会整块放弃，避免「头舱/旋前肌」这类漏网）；块数 >1 时显示百分比进度。
- **源语种识别**：中日韩字符占比 → 高辨识度功能词（es / pt / fr / de）→ 重音符号 → OpenAlex 的 `language`，默认 en；识别结果直接作为 `langpair` 源语言（此前 fr/pt/de 摘要会被误当英语送翻）。
- **目标语言默认值**：当前页面语言；若摘要原文已是该语言，自动换成另一种，避免「翻成同一语言」。
- **术语表维护**：直接改 `_data/translation_glossary.yml`（块式 YAML，字段说明见文件头注释）。**改完必须把 `version` +1**，否则浏览器缓存里的旧译文不会刷新。`python _tools/check_site.py` 会校验结构、字段、重复项、`when` 守卫，以及三语页面是否接入 `{% include papers-glossary.html %}`。
- **交互**：翻译中显示进度；成功后译文区可「隐藏译文 / 显示译文」；切换目标语言立即重译；失败时显示原因（额度用尽 / 服务不可用）并给 Google / Bing 外链（摘要预填，超长截到 1800 字符）。
- **标注**：译文旁显示实际提供方、「名录/术语校正」（发生了术语或纠错替换时）与「机器翻译，仅供参考」。
- **隐私**：只有点「翻译摘要」才会把该条摘要发给第三方；不点不发。

## 5. 缓存生成与更新

脚本：`.github/workflows/build_papers.py`（只用标准库）。

产物（字节完全相同）：

- `_data/papers.json`：Jekyll 模板用（`site.data.papers`，物种页静态渲染）。
- `papers-index.json`：公开副本，`/papers/` 页面断网 / API 失败时兜底。

结构：

```json
{
  "meta": {"generated": "...", "per_genus": 12, "counts": {...}, "abstract_policy": "...", "license": "..."},
  "genera": {
    "coptotermes": {
      "latin": "Coptotermes",
      "zh": "家白蚁属",
      "fetched_at": "2026-...",
      "papers": [
        {"id": "W...", "doi": "...", "doi_url": "...", "title": "...", "year": 2009,
         "authors": ["..."], "venue": "...", "type": "article", "language": "en",
         "cited_by": 67, "oa_url": "...", "volume": "...", "issue": "...", "pages": "...",
         "abstract": "...", "abstract_source": "openalex", "abstract_chars": 1015,
         "abstract_truncated": false}
      ]
    }
  }
}
```

命令：

```bash
# 离线校验（CI 用；不联网）
python .github/workflows/build_papers.py --check

# 初次生成 / 只补缺失和过期条目（默认含 Crossref 补摘要）
python .github/workflows/build_papers.py --write

# 全部重查
python .github/workflows/build_papers.py --write --force

# 控制时间预算，适合 CI / 本地断点续跑
python .github/workflows/build_papers.py --write --refresh --stale-days 180 --time-budget 300

# 调试单个属
python .github/workflows/build_papers.py --write --genus coptotermes

# 跳过 Crossref 补摘要；或只用 _tmp 缓存
python .github/workflows/build_papers.py --write --no-crossref
python .github/workflows/build_papers.py --write --offline

# OpenAlex 当日额度用尽时：只用 Crossref 生成剩余属（摘要覆盖率会降低）
python .github/workflows/build_papers.py --write --crossref-only
```

- 每属取 OpenAlex 相关度最高的 **12 条**（`PER_GENUS`）；323 个属。
- 网络限速：OpenAlex 约 6 req/s、Crossref 约 3 req/s；429/5xx/网络错误指数退避。
- 断点缓存：`_tmp/papers-cache.json`（已 gitignore，不提交）。中断后重跑即可续上。
- 礼貌池：可通过环境变量 `OPENALEX_MAILTO` / `CROSSREF_MAILTO` 设置联系邮箱；默认使用仓库 GitHub noreply 地址。
- OpenAlex API key：`OPENALEX_API_KEY`（免费注册，见 <https://help.openalex.org/api/authentication/>）；不设置时走 IP 共享免费额度，额度用尽会自动回退 Crossref。定时工作流从 GitHub Actions Secret 读取，绝不写进仓库或前端。
- 定时工作流：`.github/workflows/papers_refresh.yml`，每天 03:47 UTC，默认 `--refresh --stale-days 30 --time-budget 300`；手动触发可 `force`。先配好 Secret，否则工作流会显式报错停止。

## 6. 页面行为

- 输入框支持拉丁名 / 中文名 / 拼音 / 繁体自动补全（数据来自 `search-index.json`）；输入多个关键词时不做补全，直接按关键词检索。
- 关键词规则：空格 / 逗号 / 分号 / 顿号分隔（引号内为短语），最多 8 个；全部匹配（AND）。默认「仅白蚁文献」开启，取消后才查全库；「全文检索」默认关闭。
- 结果卡：来源徽章、类型、语言、OA、作者、年份、期刊、卷期页、被引数、DOI / OA 链接。
- 摘要：默认 2–3 行，点「展开摘要」看全文；无摘要时可尝试补取。
- 摘要翻译：有摘要的结果卡带「目标语言（中文 / English / Español）+ 翻译摘要」控件；中英互译时会按名录与术语表校正学名/术语，译文可显示 / 隐藏，切换目标语言会立即重译，详见第 4 节。
- 引用：每条可复制 GB/T 7714、BibTeX、RIS。
- 外链：Google Scholar / CNKI / 万方 / 百度学术 / BHL / OpenAlex / Crossref，检索词自动预填。
- URL 可分享：`/papers/?q=Coptotermes%20formosanus&syn=1&zh=1&sort=cited`；关键词查询可带 `scope=0`（取消白蚁范围）与 `full=1`（全文检索）。
- 无 JavaScript 时：只显示静态说明与外部平台入口；不出现死按钮。

## 7. 已知限制

1. **不是全库**：OpenAlex / Crossref 是开放元数据，老文献、部分中文期刊、非 DOI 文献会漏；页面明确写「候选文献，需人工核对」。
2. **摘要不全**：见上，本次缓存约 68.4%，实时检索约 60–70%；没有摘要的条目只给书目信息与外链。
3. **中文文献**：OpenAlex 对中文期刊覆盖有限；知网 / 万方无公开 API，只做外链，不抓取。
4. **国内网络**：OpenAlex / Crossref 一般可访问，但无法保证所有网络环境；缓存与外部链接是兜底。
5. **分类群同名**：属名可能与其他生物同名；分类群模式用精确短语 + 论文类型过滤，关键词模式额外追加白蚁范围过滤器，仍可能有少量误召回（尤其是「白蚁」作比喻的文献）。
6. **页面性能**：`papers-index.json` 含完整摘要（约数 MB），只在实时检索失败时加载；正常检索不下载整包。
7. **翻译额度**：MyMemory 匿名额度按访客 IP 计（约 5000 字符/天，约 2–3 篇摘要），用尽后回落到站点邮箱的共享额度（50,000 字符/天）；都失败时只能走外部翻译链接。Google 非官方接口在大陆网络通常不可达，属预期降级，不是 bug。
8. **机器翻译质量**：名录与术语表只修正「专名 / 术语」，句子仍由机翻生成，语法不通处无法保证。已知边界：缩写学名（`C. formosanus`）不还原；不在名录/术语表里的名称（如部分真菌、植物属）仍可能被翻错；`post_zh` 替换是按词表纠错，个别语境可能需要人工删改词条。西语目标没有术语干预。译文仅供筛选文献参考，不能作为引用依据。
