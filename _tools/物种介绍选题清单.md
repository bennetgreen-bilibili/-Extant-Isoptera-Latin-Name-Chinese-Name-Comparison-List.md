## 六、单页写作模板（直接对应上面的真实查询）

1. **H1**：中文名 + 拉丁名 +（别名：俗名1、俗名2）——别名是搜索匹配的关键
2. **一句话识别**：3 秒能判断「是不是这个种」
3. **形态要点**：兵蚁 / 工蚁 / 有翅成虫，各 1–2 句 + 图片
4. **和相似种的区别**：表格（黑翅土白蚁 vs 黄翅大白蚁；截头 vs 铲头堆砂白蚁；家白蚁 vs 散白蚁）
5. **危害与出现场景**：危害哪些木材 / 建筑 / 堤坝，什么季节出现（分飞期）
6. **发现后怎么处理**：写「识别—隔离—找专业防治」，不写药物推荐（避免薄内容与合规风险）
7. **分布**：已有字段，补一句「在中国哪些省份」
8. **分类位置 / 异名 / 文献**：保留现有的自动生成部分
9. **FAQ 3–5 条**：直接把真实补全词改成问句（「XX 有毒吗」「XX 会咬人吗」「XX 怎么养」「XX 和 YY 的区别」）
10. **英文摘要**：1 段，含 common name + 拉丁名（覆盖英文俗名流量）
11. **内链**：同属其他种（已有）+ 科 / 亚科 Hub + 识别图鉴页
12. **结构化数据**：在现有 Dataset JSON-LD 之外，给物种页加 FAQPage（问答段落）与 Taxon（name / alternateName / parentTaxon）

## 八、正文与推文的分工（重要修订）

「怎么养」这类操作型内容放到推文 / 博客，物种页正文只写物种介绍。理由：一个查询只由一种页面承接，两种页不互抢关键词。

| | 物种页正文（_species/） | 推文 / 博客（_posts/） |
|---|---|---|
| 读者意图 | 这个物种是什么 | 我想知道怎么养、怎么观察 |
| 文体 | 百科式物种介绍、客观陈述 | 第一人称经验、操作指南、连载 |
| 主关键词 | 中文名 / 拉丁名 / 别名 / 图片 / 特征 / 分布 / 与相似种区别 | XX 怎么养 / 饲养 / 饵料 / 温湿度 / 开箱 / 蚁后 / 多久喂一次 |
| 更新频率 | 极少（事实稳定） | 经常（系列更新，吃新鲜度） |
| SEO 角色 | 常青页，稳定收录，AI 引用与外链落点 | 抓取活跃页，把权重导向物种页 |
| 不要写 | 防治药方、饲养步骤 | 重复分类学描述、复制物种页正文 |

## 九、物种页正文模板：偏物种介绍

**写在哪**：全部写在 `<!-- AUTO:BEGIN -->` **之上**。build_species_body.py 的 assemble() 只替换 AUTO:BEGIN 与 AUTO:END 之间的内容，标记之外的文字原样保留，CI 每次构建不会覆盖手写部分。

**不要重复 AUTO 块已有的**：摘要、分类位置、分布、次异名是自动生成的，手写部分再写一遍会造成同页自我重复。手写只补自动块写不出的维度：

1. **名称与词源**：中文名来历（例：「乳白蚁」＝兵蚁受惊时分泌乳白色液体）、学名词源、命名人与年份
2. **形态识别**：兵蚁 / 工蚁 / 有翅成虫 / 蚁后 各 1–2 句，给关键鉴别特征（头形、上颚、囟、胫节距）
3. **生物学与行为**：食性、群体规模与品级分工、筑巢方式、分飞（婚飞）季节、共生关系（原生动物 / 菌圃）
4. **生境**：分布记录之外，写生境类型（原生林 / 次生林 / 城市建筑 / 堤坝）
5. **与相似种的区别**：表格，只写识别差异，不写「怎么消灭」
6. **生态作用与研究价值**：木质分解、碳氮循环、模式生物、经济或药用记录（客观陈述，不做疗效背书）
7. **延伸阅读**：链到对应推文系列与 Hub 页

篇幅 400–800 字，宁短勿凑。

## 十、推文模板：饲养 / 观察向

front matter 绑定物种，供物种页反向列出：

```yaml
---
title: "白蚁饲养笔记 01｜山林原白蚁：从一窝菌圃开始"
species: hodotermopsis-sjostedti
series: 白蚁饲养笔记
tags: [白蚁, 饲养, 原白蚁]
---
```

正文结构（固定成系列）：

1. 为什么选这个种（第一段就带物种页链接，锚文本用「中文名 + 拉丁名」）
2. 来源与合规：能否采集 / 购买、是否检疫性、明确不放生
3. 容器与温湿度（给具体数字）
4. 饵料与喂食频率
5. 观察要点：品级分工、蚁后、取食痕迹（配图）
6. 常见问题：发霉、逃逸、死亡原因
7. 更新日志与下一篇预告

## 十一、互链实现

推文 → 物种页：第一段链一次即可；锚文本用「台湾乳白蚁 Coptotermes formosanus」，不要用「点击这里」。

物种页 → 推文：在 _layouts/species.html 的「同属其他种」之前加一段 Liquid，没有推文时不渲染：

```liquid
{%- assign notes = site.posts | where: "species", page.slug -%}
{%- if notes.size > 0 -%}
<section class="species-notes">
  <h2>饲养与观察笔记</h2>
  <ul>
    {%- for post in notes limit:5 -%}
    <li><a href="{{ site.base_url }}{{ post.url }}">{{ post.title }}</a></li>
    {%- endfor -%}
  </ul>
</section>
{%- endif -%}
```

这是本次唯一要改布局的地方；布局改动会让 3,071 个页面全部重建，改完核对页面数与 sitemap 数量不变。

## 十二、饲养选题的合规边界

- 只写非检疫性、非入侵、国内有自然分布的种类：山林原白蚁（日本、中国台湾、中国南部、越南）、恒春新白蚁（东亚、台湾、日本）
- 台湾乳白蚁、黑翅土白蚁、黄翅大白蚁、散白蚁类是结构害虫：只写识别与危害，不写「怎么养」步骤
- 但「XX 好养吗」这个查询真实存在（台湾乳白蚁、黄胸散白蚁都有）。可以用同一关键词承接，但结论写「不建议养，原因是逃逸后会造成结构危害」——拿到流量，立场是劝阻
- 每篇固定一句：不放生、不跨区转运、不购买来源不明的境外活体
