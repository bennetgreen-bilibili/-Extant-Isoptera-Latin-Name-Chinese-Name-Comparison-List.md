# 属级改写规范（中国动物志·等翅目 2000 → 本站 genus 页）

## 任务
把 `_tmp/dz/gbatches/gbatch_NN.json` 里每个属的原书记述，改写成一个 JSON 数组，每个元素对应一个属页。
**不得照抄**：成稿与原文不得出现连续 12 个字符（含标点）完全相同的片段。术语（如"前胸背板""后颏宽区"）该用就用，但句子组织必须是你自己的。

## 输入字段
- page：目标页 URL（如 /genus/coptotermes/），输出必须原样带回
- genus_id / book_zh / book_latin / page_zh / family_zh / family_latin
- body：原书该属的记述（含命名引证、属征、生物学、分布、检索表、图注，混杂在一起）

## 输出字段（全部字符串，无内容时给空串）
- diagnosis：属的鉴别要点，1–2 句、60–140 字。概括该属最容易识别的组合特征（头形、囟、上颚齿式、触角节数、跗节、翅脉等中挑最关键的），不要罗列全部。
- soldier：兵蚁属征，80–220 字。
- alate：有翅成虫属征，80–220 字；原书没有就空串。
- worker：工蚁属征，有则 60–160 字，否则空串。
- biology：生物学特性与经济意义（危害对象、筑巢、食性、共生真菌等），60–200 字；原书没有就空串。
- distribution：分布（区系、国内外），20–120 字；原书没有就空串。
- taxonomy_note：仅当原书属名与本站当前属名/归属不一致时写 1–2 句说明（如书中置于某科、现已独立成科），否则空串。
- en：英文摘要 60–90 词，覆盖 diagnosis 与兵蚁要点。

## 必须丢弃的内容
- 命名引证（"Wasmann,1896,Neue Termitophilen…type species: …"）、文献缩写、模式种学名的引证格式；
- 分种检索表（"10. 头长至上颚基1.32 mm… 河口乳白蚁"这类成串条目）；
- 图注（"图130 中国乳白蚁属 Coptotermes 分布图(朱世模，1996)"）；
- 量度数字串与"mm"计量表；散文里的相对量度（如"上颚长约为头壳长的四分之三"）可以保留。

## 体例
- 全角中文标点；数字用汉字（"13—17节"→"十三至十七节"，"1.5倍"→"一点五倍"）；拉丁学名保留原样（斜体标记不要写，直接写属名）。
- 不要 markdown 记号、不要 HTML 标签、不要列表符号。
- 语气：志书体，客观陈述，不用"我们""可以看到"。

## 自检闭环（必须 0 条 HARD 才算完成）
写完 `_tmp/dz/gout/gbatch_NN.json` 后运行：

```
PYTHONIOENCODING=utf-8 python _tmp/dz/check_genus.py _tmp/dz/gout/gbatch_NN.json --n 12
```

每行 `HARD 20字 /genus/xxx/ soldier | 相同片段` 都要改写：换句序、换句式、合并或拆分、换同义术语、数字改汉字。
反复改到 `hard fields: 0`（exit 0）。
