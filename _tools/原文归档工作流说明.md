# 原文归档工作流说明

> 目标：在「文献检索器」缓存 _data/papers.json 的基础上，把标记为开放获取（oa_url 非空）、
> 且尚未归档的论文**合法 OA 全文**（出版社 PDF 或 Europe PMC 的 JATS XML）下载进本地文库
> _unpublished/文库/，并在 .sources/ 证据账本登记一条来源记录，最后把全文库重新打包成
> 加密备份 .library-vault/ 提交。**查不到合法 OA 全文的论文，自动退回把完整摘要作为「摘要全文」
> 存进文库 _unpublished/文库/（.sources/ 只记元数据、注明「仅有摘要，无 OA 全文」），不硬编全文。

## 1. 与「爬论文 + 摘要」的关系

- 上游：.github/workflows/build_papers.py 只抓**元数据 + 摘要**，不下载 PDF（政策见
  _tools/文献检索器说明.md §3）。它产出的 _data/papers.json 里每条带 oa_url（OpenAlex 的
  open_access.oa_url），标记该 DOI 是否有开放获取版本。
- 本工作流：_tools/fetch_fulltext.py 读取 papers.json，只挑（oa_url 非空 或 有摘要）、有 doi、且尚未归档的
  条目，按被引数从高到低处理：有 OA 抓全文，无 OA 退回把完整摘要存进文库。**它不重复爬元数据**；两个工作流各司其职，
  可独立、也可串行运行。
- 产出：全文只进 _unpublished/文库/（gitignore，不发布），账本 .sources/（进仓库，只存元数据 +
  短摘录），加密备份 .library-vault/（进仓库，恢复全文库用）。三者对应 AGENTS.md §1.4 / §1.4.2。

## 2. 政策红线（只走合法 OA）

- 只下载作者/出版商已合法开放的版本：Unpaywall 标记 is_oa、OpenAlex 的 OA location、
  Europe PMC 的 isOpenAccess + fullTextXML。
- 不绕过付费墙、不破解访问控制；HTML 落地页一律不下（只下 PDF 或 JATS XML）。
- 付费墙后的文章查不到合法 OA 时，**不硬编全文**，退回把完整摘要作为「摘要全文」存进
  _unpublished/文库/（full.txt = 摘要，不截断），账本 .sources/ 只留元数据 + 短摘录，
  notes 注明「仅有摘要，无 OA 全文」+ 摘要来源与字数（符合 AGENTS.md §1.6 红线）。
- 预印本与正式版是两条记录（DOI 不同），reliability 标 unverified，引用以正式版为准。

## 3. 解析与下载顺序

对每个候选 DOI，先并行问四个元数据源，把**所有**可下载地址汇成候选清单
（一篇文章常有 2–4 个 OA 副本，任何一条能下到就成功），排序后逐个尝试（取到即停）：

1. 队列里显式给的 URL（--queue 手工维护时用）；
2. Unpaywall（https://api.unpaywall.org/v2/{doi}?email=... ）：**全部** oa_locations 的
   url_for_pdf（不是只看 best_oa_location）；
3. Europe PMC（按 DOI 查 PMC 记录，取 fullTextXML 的 JATS XML；JATS 比双栏 PDF 抽取干净，
   因此排在最前）。XML 端点失败时，再退 PMC 自己的 PDF 直链；
4. OpenAlex（best_oa_location.pdf_url + locations[].pdf_url）；
5. Semantic Scholar openAccessPdf（补一条，常指向机构库/doi.org 落地页）；
6. 站点迁移地址（旧 Hindawi → Wiley `doi/pdfdirect/<doi>`，仅换官方域名，不构造未公开地址）；
7. 官方落地页（blog/出版社页）里的 `citation_pdf_url` / `<link type="application/pdf">`。

排序规则：JATS XML 最先 → 未被冷却的站点优先 → `host_type=repository`（机构库/仓储）优先于
出版社 → 来源优先级；同一 URL 去重，最多试 5 条。

**当 PDF 直链返回的是网页**（Springer 的 JS 拦截页、doi.org 落地页、handle/机构库条目页）时，脚本
会从该网页里读 `citation_pdf_url` 抽回真正的 PDF 地址再试一次——这一类在老文献里很常见，
旧版本会把它们直接记成失败。

单条候选超时 25s、单篇最多 90s；同一站点连续 3 次硬失败（403/404/410/451/返回网页）就写进
`_data/fulltext_hosts.json`，冷却 120 天不再尝试（省下的预算给没撞过的站点）。

只返回 PDF 或 XML；下载后调用 _tools/sources.py library-add 入库（--kind paper；
reliability 映射：article/review → peer_reviewed，preprint/预印本域 → unverified，
book-chapter → reference）。PDF 抽取依赖 pymupdf；XML 走 JATS 去标签。
所有候选都取不到时，退回把完整摘要存进文库（见 §2），并按失败原因打标：
`abstract-blocked`（站点拦截/返回网页，180 天后重试）/
`abstract-no-oa`（查不到 OA 全文，或 OA 只给落地页而页面没自报 PDF 直链，120 天后重试）/
`abstract-download-failed`（瞬时失败，21 天后重试）。
落地页（`kind=landing`：doi.org、handle、出版社文章页）只用来读 `citation_pdf_url`，读不到不算该站拦截，
也不记 host 失败——否则正常返回 HTML 的解析器会被误判成拦爬虫。

### 3.1 扫描件 OCR 兜底

下载到 PDF 后，先探测文字层：若前 10 页抽出的文字 < 500 字，判为**扫描件**（无文字层）。
此时若本机能找到 tesseract（自动探测 PATH、C:\Program Files\Tesseract-OCR\tesseract.exe，
或 --tesseract-cmd 显式指定），就用 pymupdf 逐页渲染成 PNG（300 dpi）→ tesseract OCR →
把 OCR 文本经 sources.py library-add --text 入库（原件 PDF 仍归档在 source/）。notes 会注明
「扫描件经 tesseract OCR，未经人工校对」。OCR 语言按论文 language 自动映射（en→eng、
es→spa、zh→chi_sim），也可 --ocr-langs 覆盖；默认只 OCR 前 60 页（--ocr-max-pages）。
找不到 tesseract 时跳过该扫描件，缓存记 scanned-needs-ocr（不再伪成功归档空全文）。

## 4. 本地命令

先设邮箱（Unpaywall 必填；缺省则跳过 Unpaywall，仍可用 OpenAlex / Europe PMC）：

> Unpaywall 用邮箱做礼貌限流与联系（免费配额 100,000 calls/day），**必须是真实个人邮箱**；占位邮箱（example.com 一类）
> 会返回 HTTP 422「Please use your own email address」，脚本会自动降级到 OpenAlex / Europe PMC。

    export UNPAYWALL_EMAIL=you@example.com
    # PowerShell: $env:UNPAYWALL_EMAIL="you@example.com"

离线校验 + 计划（只读，不联网、不改任何文件）：

    python _tools/fetch_fulltext.py --check

从 papers.json 挑被引最高的 20 条未归档 OA 论文生成队列（不下载）：

    python _tools/fetch_fulltext.py --discover 20

只解析 OA 链接、不下载不入库（先看会抓到什么）：

    python _tools/fetch_fulltext.py --dry-run --discover 20 --limit 5

真正执行爬取 + 归档（--limit 0 不限条数，受 600 秒网络预算约束）：

    python _tools/fetch_fulltext.py --write --discover 40 --limit 0 --time-budget 600

参数：--queue（默认 _tmp/fulltext-queue.json）、--cache（默认 _tmp/fulltext-cache.json）、
--tmp（默认 _tmp/fulltext）、--discover N、--limit N（0=不限）、--time-budget 秒（0=不限）、
--stale-days（失败条目多少天内不重试，默认 30）、--force（忽略失败缓存全重试）、
--dry-run、--check、--write。扫描件 OCR 相关：--tesseract-cmd（tesseract 路径，缺省自动探测）、
--tessdata-dir（语言数据目录，缺省自动探测 _tmp/tessdata，否则用系统默认）、
--ocr-langs（OCR 语言，缺省按论文 language 映射）、--ocr-max-pages（默认 60）。

语言包：本机 tesseract 装在 C:\Program Files\Tesseract-OCR\tesseract.exe（不在 PATH），
自带英文 eng。中文 chi_sim、西语 spa 已下载到 _tmp/tessdata/（gitignore），脚本自动经
--tessdata-dir 使用；缺中文/西语包时 OCR 会回退 eng 或失败（见 §9）。

## 5. 断点缓存与队列

- 队列 _tmp/fulltext-queue.json：候选 DOI 列表（--discover 生成/合并），gitignore，不提交。
- 缓存 _tmp/fulltext-cache.json：每条的状态（ok / resolved / abstract-archived / abstract-blocked /
  abstract-no-oa / abstract-download-failed / no-fulltext / error）+ 尝试时间 + `next_try`（下次最早重试时间戳）；
  本地断点续跑用；失败条目按 `next_try` 与 --stale-days 双重冷却。
- 站点冷却 _data/fulltext_hosts.json（**进仓库**）：每个 host 的连续硬失败次数、最后原因、
  `blocked_until`。连续 3 次硬失败 → 冷却 120 天，冷却期内连试都不试。
- **权威「已归档」判定不是缓存，而是文库**：_unpublished/文库/manifest.json 与
  .sources/index.json 的 canonical_key（doi: 前缀）。所以即使删掉缓存，也不会重复下载已入库的论文。
- CI 每次全新 checkout，缓存与队列不持久化；但文库从 .library-vault/ 恢复、站点冷却从
  _data/fulltext_hosts.json 恢复，所以拦爬取的站点不会被每周重新硬撞一遍。

## 6. .sources 字段（每条归档记录的落点）

- canonical_key：doi:<小写去前缀>，与网页/文件来源同源自动合并，复用原 Sxxxx。
- title/authors/year/publisher/lang/license：取自 OA 元数据（Unpaywall/OpenAlex/Europe PMC）。
- reliability：按 §3 映射；notes 记「OA 全文自动归档（来源 + 类型）…引用以出版方原文为准」。
- 全文实际落在 _unpublished/文库/<slug>/full.txt（+ source/<原件>），账本只留元数据 + 短摘录
  （AGENTS.md §1.6 红线）。
- 无 OA 全文时：完整摘要同样作为「摘要全文」入库（full.txt = 摘要，source/<原件> = 摘要 txt），
  notes 注明「仅存完整摘要，无 OA 全文」，账本不塞逐字摘要。

## 7. CI 工作流

.github/workflows/fulltext_archive.yml：每周一 04:23 UTC + 手动触发。步骤：

1. pip install pymupdf（PDF 抽取需要）+ apt 装 tesseract-ocr / -chi-sim / -spa（扫描件 OCR 兜底）；
2. 校验 Secret：LIBRARY_VAULT_KEY（加密备份口令）、UNPAYWALL_EMAIL（礼貌邮箱）；
3. library_vault.py unpack --force 恢复 _unpublished/文库；
4. fetch_fulltext.py --write --discover 40 --limit 0 --time-budget 300（手动可改；limit 默认 0 不限）；
5. sources.py check --strict 校验账本；
6. library_vault.py pack 重新打包加密备份；
7. git add .library-vault/ .sources/ _data/fulltext_hosts.json 并提交推送（github-actions[bot]）。
   不触发 Pages：.sources/、.library-vault/、_data/fulltext_hosts.json 不影响站点渲染。
   站点级冷却（哪些站点长期拦爬取）必须进仓库，否则每轮 CI 都从零开始硬撞同一批墙。

手动触发可调 discover / limit / time-budget / force。

## 8. 本地优先 vs CI 全自动（取舍）

- **本地优先（推荐默认）**：vault 口令 _tmp/vault.key 只在本机，CI 不碰明文；本地跑
  fetch_fulltext.py --write 后手动 library_vault.py pack 并提交。优点：口令不进云端 Secret、
  无 CI 瞬时下载版权 PDF 的问题；缺点：要人手动触发。
- **CI 全自动**：把 LIBRARY_VAULT_KEY 配成 GitHub Secret，工作流每周自动跑。优点：省心；
  代价：1) 口令进 GitHub Secret（受账号安全保护，但毕竟在云端）；2) CI runner 瞬时下载版权 PDF
  再加密提交，本地用户需事后 unpack 才能拿到明文全文（这与「全文只在本机」的定位有张力）。

当前仓库已同时提供两种入口：本地用 fetch_fulltext.py 直接跑；CI 用 fulltext_archive.yml
（要全自动才配 LIBRARY_VAULT_KEY secret）。

## 9. 已知限制

1. 覆盖 papers.json 里有 oa_url 或有摘要的条目；既无 OA 标记也无摘要的老文献、中文期刊、非 DOI
   文献不在此列。
2. OpenAlex/Unpaywall 的 OA 标记与真实可下载性有出入：标记 OA 但 PDF 链接 403/失效的情况会记为
   `abstract-blocked` 并把该站点放进 120 天冷却；OA 只给落地页、页面也没自报 PDF 地址的记
   `abstract-no-oa`（120 天）；瞬时失败记 `abstract-download-failed`（21 天）。
   出版社 Cloudflare（Wiley / Elsevier / OUP / T&F / BHL partpdf）对数据中心 IP 基本一律 403，
   这一部分再改代码也拿不到全文——只能靠仓储副本（SciELO / Zenodo / archive.org / PMC）或人工获取。
3. 出版社 PDF 文本抽取非排版原貌（上标引文编号、表格、图注会错位）；正式引用前核对出版方原文
   （与 AGENTS.md §1.4.1 一致）。
4. Europe PMC 只覆盖生物医学/生命科学子集，白蚁分类学文献命中率有限。
5. CI 不持久化队列/断点缓存，但有 `_data/fulltext_hosts.json` 的站点冷却与
   `.sources` 里的 `next_try` 时间戳：拦站点不会每周重新硬撞（见 §5）。
6. 扫描件 OCR 的精度有限：分类学文献里的拉丁学名、斜体、特殊符号易错，OCR 文本须人工校对后才能
   正式引用；中文（chi_sim）/西语（spa）用 tessdata_fast 快速包，精度低于完整包。
